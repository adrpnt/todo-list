# TODO LIST

Aplicação desenvolvida para estudos de React.

Feito com **React 19 + TypeScript + Vite**.

## Rodando o projeto

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`.

## Estrutura

```text
src/
  components/   Seções e componentes de UI da página
  types/      Tipos compartilhados do formulário
```

## Build de produção

```bash
npm run build
npm run preview
```

Os arquivos otimizados são gerados em `dist/`.
